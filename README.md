# Convite Digital — Aniversário do Rafael

Projeto Vue 3 + Vite + Tailwind CSS.

## Usar

```bash
npm install
npm run dev
```

Substitua os arquivos `public/images/rafael-theme.webp` e `public/audio/trilha.mp3` pelos assets finais antes de publicar.

## Otimização dos arquivos

- Imagem WebP com menos de 300 KB.
- Áudio MP3 leve, abaixo de 2 MB e em loop.
